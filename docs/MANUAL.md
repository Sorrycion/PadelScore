# ✍️ Reglamento Manual individual

**Objetivo:** un torneo individual flexible, en el que los organizadores (o los jugadores con la contraseña del torneo) arman cada set a mano, pero los puntos se cuentan igual que en la Liga de amigos.

## Formato

- Se eligen los jugadores del torneo al crearlo; la lista se puede cambiar en cualquier momento (los resultados anteriores se conservan).
- El torneo se juega por **jornadas**. Crear una jornada solo guarda la fecha: no se crean sets automáticamente.
- Cada **set se crea a mano**: se eligen la cancha y las dos parejas. Puede haber cualquier número de sets y de canchas en una jornada, y un jugador puede jugar varios sets.
- Un set puede terminar con cualquier marcador (por ejemplo si se acaba el tiempo) y también puede quedar empatado.

## Puntuación (igual que la Liga de amigos)

Cada set se puntúa por separado, sin importar la cancha:

| Resultado del set | Puntos por jugador |
|---|---|
| Pareja ganadora | 9 + 1 por set ganado = **10** |
| Pareja perdedora | **6** |
| Set empatado | **9** cada uno de los cuatro |

- Los puntos de un jugador en la jornada son la suma de sus sets, y la clasificación del torneo suma las jornadas.
- Un jugador marcado como **ausente** en una jornada suma 0 puntos en ella, aunque un suplente juegue en su lugar.

## Clasificación

- Se ordena por puntos totales; los jugadores con los mismos puntos comparten posición.
- Solo cuentan los sets de este torneo: cada torneo tiene su propia clasificación.
